# Kairo Realty

Website for Kairo Realty: *Intelligent Real Estate, Perfectly Timed.*

A static, dependency-free site. Open `index.html` in a browser or deploy the folder to any static host (Netlify, Vercel, GitHub Pages).

## Before launch
- Connect the lead form in `index.html` (search for `TODO: send to CRM`) to your CRM or lead-routing endpoint.
- Fill in footer links marked `data-todo`: NYS Fair Housing Notice, Standard Operating Procedures, Privacy.
- Replace the Moment Score sample figures with live market data.
- Add a founder headshot in place of the monogram.
